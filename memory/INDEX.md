# 项目记忆索引

本目录只保存对仓库长期有效的通用事实，不保存机器状态快照、账号、频道、会话转录或临时故障日志。

| 文件 | 内容 |
| --- | --- |
| `DECISIONS.md` | 持久架构与治理决策 |
| `DEPLOYMENT.md` | 环境驱动的安装、升级、验证与回滚 |
| `RUNBOOK.md` | 日常开发、运行和排障步骤 |
| `PITFALLS.md` | 已验证的常见失败模式与防复发措施 |
| `TASK_HISTORY.md` | 精简后的项目里程碑 |

## 当前事实

- 本仓库是通用工作流基础设施与配置备份。
- 目标项目和 Runtime 通过参数或环境变量注入。
- 流水线事实源是代码、测试、Git、结构化产物和实际命令结果。
- 机器运行态必须现场核验，不从本目录推断。
