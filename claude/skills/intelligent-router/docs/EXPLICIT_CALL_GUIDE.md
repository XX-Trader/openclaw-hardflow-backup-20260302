# 显式调用系统 - 使用指南

> **版本**: 1.0.0
> **更新时间**: 2026-01-25
> **作者**: superma

---

## 📖 概述

显式调用系统是智能路由系统的一部分，允许用户通过明确的语法格式直接调用技能、Subagent 或组合，无需依赖关键词模糊匹配。

### 🎯 核心优势

| 对比项 | 关键词匹配 | 显式调用 |
|--------|-----------|---------|
| **准确性** | 可能误触发 | 100% 精确 |
| **意图表达** | 模糊 | 明确 |
| **优先级** | 低 | 最高 |
| **适用场景** | 简单任务 | 复杂/专业任务 |

---

## 🚀 快速开始

### 三种调用格式

#### 1️⃣ 技能调用
```
[调用技能: <技能名>] 执行 <任务描述>
```

**示例**：
```markdown
[调用技能: pdf] 提取这个 PDF 中的所有表格数据
[调用技能: frontend-design] 设计一个深色模式的登录页面
[调用技能: auto-fix] 修复 src/auth.js 中的所有测试失败
```

#### 2️⃣ Subagent 调用
```
[调用 Subagent: <Agent 类型>] 执行 <任务描述>
```

**示例**：
```markdown
[调用 Subagent: smart-flow:python-expert] 优化这段代码的性能
[调用 Subagent: smart-flow:database-architect] 设计一个高并发的订单系统
[调用 Subagent: pr-review-toolkit:code-reviewer] 审查这个 PR 的安全性
```

#### 3️⃣ 组合调用
```
[调用组合: <组合名>] 执行 <任务描述>
```

**示例**：
```markdown
[调用组合: 量化交易组合] 分析这个策略的风险收益比
[调用组合: 全栈开发组合] 从零开发一个待办事项应用
[调用组合: 代码审查组合] 审查 PR #123 的代码质量、安全性和性能
```

---

## 📋 优先级规则

```
1. 显式调用声明（最高优先级）
   ↓
2. 用户显式指定（如"使用 XXX agent"）
   ↓
3. 关键词匹配
   ↓
4. 文件类型检测
   ↓
5. 默认处理
```

### 示例对比

| 用户输入 | 实际调用 | 原因 |
|---------|---------|------|
| `[调用技能: pdf] 新增功能` | **pdf 技能** | 显式调用优先 |
| `新增功能：用户登录` | **feature-development** | 关键词匹配 |
| `使用 python-expert 优化` | **python-expert** | 显式指定 |

## ✅ 正确使用姿势

### DO - 推荐

✅ **明确指定技能**
```markdown
[调用技能: pdf] 提取第 5-10 页的表格
```

✅ **详细描述任务**
```markdown
[调用 Subagent: smart-flow:python-expert]
优化以下代码的内存使用：
- 减少不必要的对象创建
- 使用生成器代替列表
- 添加内存分析注释
```

✅ **使用组合处理复杂任务**
```markdown
[调用组合: 全栈开发组合]
开发一个用户认证系统：
- 前端：登录/注册表单
- 后端：JWT 认证 API
- 数据库：用户表设计
```

### DON'T - 避免

❌ **意图不明确**
```markdown
提取 PDF 数据  # 可能触发多个技能
```

❌ **嵌套调用标记**
```markdown
[调用技能: pdf] [调用技能: xlsx] 转换文件  # 混乱
```

❌ **在任务描述中使用调用格式**
```markdown
[调用技能: docx] 帮我写一个 "[调用技能: pdf] 的使用教程"  # 歧义
```

## 🎯 常见场景

### 场景 1: 文档处理

**任务**: 将 PDF 转换为 Word 文档

**❌ 模糊表达**:
```
把这个 PDF 转成 Word
```

**✅ 显式调用**:
```
[调用技能: pdf] 提取 PDF 中的所有文本和表格
[调用技能: docx] 创建一个 Word 文档，包含提取的内容
```

---

### 场景 2: 代码优化

**任务**: 优化 Python 代码性能

**❌ 模糊表达**:
```
优化这段代码
```

**✅ 显式调用**:
```
[调用 Subagent: smart-flow:python-expert]
优化以下代码的性能要求：
- 时间复杂度从 O(n²) 降到 O(n)
- 减少内存占用
- 添加性能测试
```

---

### 场景 3: 复杂功能开发

**任务**: 开发一个完整的交易策略

**❌ 模糊表达**:
```
开发一个交易策略
```

**✅ 显式调用（组合）**:
```
[调用组合: 量化交易组合]
开发一个均值回归策略：
- 入场条件：价格偏离 20 日均线 2%
- 出场条件：回归至 0.5% 以内
- 风险控制：止损 3%，止盈 5%
- 回测周期：2023-01-01 至今
```

## 🔧 故障排查

### 问题 1: 显式调用被忽略

**可能原因**：
1. 格式错误（括号、冒号位置）
2. 技能/Agent 名称不存在
3. 中文输入法的全角符号

**解决方案**：
```markdown
# ❌ 错误：全角括号
［调用技能：pdf］提取数据

# ✅ 正确：半角括号
[调用技能: pdf] 提取数据
```

---

### 问题 2: 调用了错误的技能

**可能原因**：
1. 技能名称拼写错误
2. 系统回退到关键词匹配

**解决方案**：
```
# 检查技能名称是否正确
# 查阅 SKILLS_INDEX.md 获取完整列表

# 示例：正确名称
[调用技能: xlsx]  # ✅ 正确
[调用技能: excel] # ❌ 错误，应该是 xlsx
```

---

### 问题 3: 任务描述没有被识别

**可能原因**：
1. 任务描述太长，被截断
2. 格式中缺少"执行"关键字

**解决方案**：
```markdown
# 方案 1: 使用"执行"关键字（可选）
[调用技能: pdf] 执行提取表格

# 方案 2: 直接写任务描述
[调用技能: pdf] 提取所有表格并保存为 CSV
```

## 🎓 最佳实践

### 1. 明确任务边界

```markdown
# ❌ 模糊
[调用技能: pdf] 处理这个文件

# ✅ 明确
[调用技能: pdf] 提取第 1-5 页的所有表格，并分析数据趋势
```

---

### 2. 利用组合能力

```markdown
# 单个技能：只能做一件事
[调用技能: pdf] 提取数据

# 组合：可以处理复杂任务
[调用组合: 数据分析组合]
1. 提取 PDF 数据
2. 清洗异常值
3. 生成可视化图表
4. 输出分析报告
```

---

### 3. 指定技术栈细节

```markdown
# ❌ 太笼统
[调用 Subagent: backend-developer] 创建 API

# ✅ 明确技术栈
[调用 Subagent: smart-flow:backend-developer]
使用以下技术栈创建 RESTful API：
- 框架：FastAPI
- 数据库：PostgreSQL + SQLAlchemy
- 认证：JWT
- 文档：Swagger/OpenAPI
```
