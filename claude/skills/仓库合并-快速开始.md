## ⚠️ 前置条件

在调用"仓库合并"之前，请确保：

1. **Git工作区干净**
   ```bash
   git status
   # 应该显示: nothing to commit, working tree clean
   ```

2. **已配置上游仓库**（或我会帮你配置）
   ```bash
   git remote -v
   # 应该看到: upstream 或 fmz-source
   ```

3. **在正确的分支上**
   ```bash
   git branch --show-current
   # 应该在: main 或 master
   ```

## 💡 提示

1. **自动检测优先**：尽量让我自动检测上游仓库，成功率更高
2. **备份自动创建**：每次合并都会自动创建备份，安全无忧
3. **分步合并**：冲突文件会按风险等级自动分类，你可以逐步处理
