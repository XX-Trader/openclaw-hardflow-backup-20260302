# 高德地图 MCP 使用说明

> 本目录包含高德地图 MCP 服务的详细配置说明。

**版本**: 1.0.0
**NPM 包**: `amap-maps-mcp-server`
**状态**: ✅ 已全局安装

---

## 快速开始

### 1. 获取高德地图 API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册/登录账号
3. 控制台 → 应用管理 → 我的应用 → 创建新应用
4. 添加 Key，选择「Web端(JS API)」或「Web服务」
5. 复制获得的 Key

### 2. 配置环境变量（可选）

在 `travel-skills` 根目录的 `.env` 文件中添加:

```
AMAP_API_KEY=你的高德地图密钥
```

**注意**: 高德地图 MCP 通常已全局安装，可能不需要单独配置。

### 3. 启动高德地图 MCP

```bash
cd C:\Users\superma\.claude\skills\travel-skills
npm run amap
```

## MCP 可用工具

### 天气查询 (`amap_weather`)
- **功能**: 查询实时天气和预报
- **参数**: `city` (城市名称或 adcode)
- **返回**: 实时天气、温度、风力、未来预报

### 地址解析 (`amap_geocode`)
- **功能**: 地址 → 坐标转换（GCJ-02坐标系）
- **参数**: `address` (待解析的地址), `city` (城市)
- **返回**: `{ lat, lng, formatted_address, ... }`

### 逆地址解析 (`amap_regeocode`)
- **功能**: 坐标 → 地址转换
- **参数**: `location` (经度,纬度)
- **返回**: 详细地址信息、POI、道路等

### 周边搜索 (`amap_around_search`)
- **功能**: 搜索周边POI
- **参数**: `location` (经度,纬度), `keywords` (关键词), `radius` (半径)
- **返回**: 附近地点列表 `{ name, location, address, distance, ... }`

### 关键词搜索 (`amap_text_search`)
- **功能**: 关键词搜索POI
- **参数**: `keywords` (关键词), `city` (城市)
- **返回**: 地点列表

### 路线规划 (`amap_direction`)
- **功能**: 计算两点间路线
- **参数**: `origin` (经度,纬度), `destination` (经度,纬度), `strategy` (路线策略)
- **返回**: 距离、时长、路线步骤

### 距离测量 (`amap_distance`)
- **功能**: 测量两点间距离
- **参数**: `origins` (起点列表), `destination` (终点)
- **返回**: 距离和用时

## 在旅游技能中的应用

高德地图主要用于：

1. **天气查询**: 实时天气和预报，用于装备推荐
2. **位置信息**: 获取目的地的精确坐标
3. **周边搜索**: 搜索附近的餐厅、停车场、景点等
4. **路线规划**: 开车路线、徒步路线的距离和时间估算

### 典型应用流程

```
用户提问 → 触发旅游技能
    ↓
查询目的地天气 → 装备推荐
    ↓
搜索周边餐厅/停车场 → 实用信息
    ↓
规划驾车路线 → 时间/距离估算
    ↓
生成完整攻略
```

## 坐标系统

高德地图使用 **GCJ-02** 坐标系（国测局坐标，又称火星坐标）：

| 服务 | 坐标系 | 说明 |
|------|--------|------|
| 高德地图 | GCJ-02 | 国测局坐标（火星坐标） |
| 腾讯地图 | GCJ-02 | 与高德相同 |
| 百度地图 | BD-09 | 百度坐标，在 GCJ-02 基础上加密 |
| Google Maps | WGS-84 | 地球坐标（国内需转换） |

**转换**: 如需在百度地图显示，需将 GCJ-02 转换为 BD-09。

## 故障排除

### 问题: "KEY 不存在"
- **解决**:
  1. 确认 API Key 正确
  2. 检查应用服务类型选择正确

### 问题: "无效的请求"
- **解决**:
  1. 检查参数格式是否正确
  2. 确认坐标格式为 `经度,纬度`

### 问题: "MCP 连接失败"
- **解决**:
  1. 确认高德地图 MCP 已全局安装
  2. 运行 `npm list -g @amap/amap-maps-mcp-server` 检查
  3. 运行 `npm run amap` 查看 MCP 日志
