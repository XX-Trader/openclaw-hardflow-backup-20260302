# 部署后验收

本 Skill 保留 `deployment-test` 名称供控制面能力绑定使用，实际验证统一进入 [project-delivery-pipeline](../project-delivery-pipeline/SKILL.md) 的验证和部署验收阶段。

## 验收矩阵

| 层级 | 项目提供的输入 | 最低证据 |
| --- | --- | --- |
| 进程或容器 | 状态命令 | 目标实例与版本一致 |
| 接口 | 请求命令与断言 | 状态、结构和关键字段符合契约 |
| 页面 | 浏览器测试命令 | 真实交互断言和失败截图 |
| 数据 | 只读核对命令 | 写入、读取或迁移结果符合项目约束 |
| 回滚 | 回滚命令与复验 | 旧版本恢复且健康检查通过 |

## 规则

- 不预设服务、端口、接口、账号或页面选择器。
- 不使用模拟 UI 结果替代浏览器执行证据。
- 测试账号和密钥只从目标环境的 Secret Store 注入。
- 任一必选断言失败时，结果保持失败并返回对应阶段。
