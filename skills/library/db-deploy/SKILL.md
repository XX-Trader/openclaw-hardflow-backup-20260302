# 通用部署门禁

本 Skill 保留 `db-deploy` 名称以兼容现有能力绑定，部署执行统一归属 [project-delivery-pipeline](../project-delivery-pipeline/SKILL.md)。名称不限定数据库、框架、操作系统或托管平台。

## 输入

- 目标项目目录和项目键；
- 已通过验证与代码审查的补丁；
- 显式 `deployment-command`；
- 项目定义的烟测命令、成功条件和超时；
- 可执行的回滚命令或回滚说明。

## 门禁

1. 部署需求必须出现在当前需求包中。
2. 部署命令为空时跳过部署阶段并记录原因。
3. 执行前保存版本、配置摘要和回滚点。
4. 命令退出码、服务存活和接口响应只作为分层证据。
5. 烟测达到项目验收条件后才记录部署完成。

项目路径、主机、端口、账号、密钥、服务名和命令均由环境变量或项目配置注入，仓库不保存真实值。
