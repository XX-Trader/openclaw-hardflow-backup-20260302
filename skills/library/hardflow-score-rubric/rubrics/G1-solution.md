# G1 Solution — 评分标准

> 适用 Gate：`solution` | 维度数：5 | 阈值：overall ≥ 92

## fit_for_problem (问题匹配度)
满分（95-100）：方案精准解决核心问题，无过度设计。扣分：过度设计 -8、解决了非核心问题 -10

## feasibility (可行性)
满分（95-100）：技术选型成熟，团队有能力，资源充足。扣分：使用未验证技术 -10、依赖不存在的 API -15

## complexity_control (复杂度控制)
满分（95-100）：核心逻辑 ≤ 3 个模块，无循环依赖。扣分：模块超过 5 个 -5、存在循环依赖 -10

## alternatives_evaluation (替代方案评估)
满分（95-100）：列出 ≥ 2 个替代方案并说明选择原因。扣分：无替代方案讨论 -10

## risk_mitigation (风险缓解)
满分（95-100）：每个技术风险有具体应对措施。扣分：有风险无应对 -8、忽略部署风险 -5
