# G5 Release — 评分标准

> 适用 Gate：`release` | 维度数：5 | 阈值：overall ≥ 92

## test_coverage (测试覆盖率)
> 此维度以确定性检查为主（70% 确定性 + 30% reviewer）

满分（95-100）：覆盖率 ≥ 90%，核心路径 100% 覆盖。
扣分：覆盖率 < 80% -10、核心路径未覆盖 -15

## regression_result (回归测试)
> 此维度以确定性检查为主（70% 确定性 + 30% reviewer）

满分（95-100）：所有回归用例通过，无新增失败。
扣分：每个新增失败 -5、原有用例失败 -10

## deployment_reliability (部署可靠性)
满分（95-100）：部署脚本幂等、有健康检查、有自动回滚。
扣分：部署非幂等 -10、无健康检查 -8、无回滚机制 -10

## rollback_readiness (回滚就绪)
满分（95-100）：有明确回滚方案、数据库变更可逆。
扣分：无回滚方案 -15、Schema 变更不可逆 -10

## observability (可观测性)
满分（95-100）：关键路径有监控指标、有告警规则。
扣分：无监控指标 -10、无告警规则 -5
