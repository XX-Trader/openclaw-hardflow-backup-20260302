# G3 Backend — 评分标准

> 适用 Gate：`backend` | 维度数：5 | 阈值：overall ≥ 93

## architecture_design (架构设计)
满分（95-100）：分层清晰（Controller/Service/Repository）、依赖方向单一、核心函数 ≤ 50 行。
扣分：无分层 -15、循环依赖 -10、单函数超 100 行 -8

## api_contract_quality (API 契约质量)
> 此维度与确定性检查（typecheck）加权合并：30% 确定性 + 70% reviewer

满分（95-100）：所有 API 有完整的请求/响应类型定义、错误码文档化、版本号标记。
扣分：缺少类型定义 -10、无错误码文档 -5、无版本号 -3

## data_flow_integrity (数据流完整性)
满分（95-100）：数据从入口到持久化无隐式转换、所有外部输入有校验。
扣分：存在隐式类型转换 -8、外部输入未校验 -10、SQL 拼接 -15 (veto)

## maintainability (可维护性)
满分（95-100）：代码有清晰注释（公开函数 100% 文档）、测试覆盖率 ≥ 80%。
扣分：公开函数无注释 -8、魔法值 -5、死代码未清理 -3

## scalability (扩展性)
满分（95-100）：关键路径支持水平扩展、无全局可变状态、配置外部化。
扣分：存在全局可变状态 -10、配置硬编码 -8、单点瓶颈 -5
