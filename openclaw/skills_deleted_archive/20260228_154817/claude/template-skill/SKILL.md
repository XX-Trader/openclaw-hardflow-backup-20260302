# template-skill

## 用途
这是一个模板技能，用于创建新技能时快速起步。

## 适用场景
- 需要新建一个专业技能目录时
- 需要统一 SKILL.md 结构时

## 使用方法
1. 复制本模板目录为新技能目录。
2. 修改 frontmatter 的 
ame、description、ersion。
3. 按实际任务补充触发条件、执行流程、约束和示例。
4. 删除模板性质描述，确保内容可直接执行。

## 最小质量检查
- frontmatter 完整且可解析。
- 内容没有占位文本。
- 使用步骤可执行。
