# Log Viewer - 通用日志查看器

用于处理大日志文件的去重与分析工具。

## 快速开始

```bash
# 基础使用
python log_deduplicator.py app.log

# 指定输出文件
python log_deduplicator.py app.log -o result.log

# 预览模式（不实际写入）
python log_deduplicator.py app.log --dry-run
```

## 输出文件

处理后会生成以下文件：

1. **{文件名}-deduped.log** - 去重后的日志文件
2. **report.txt** - 异常统计报告
3. **order_failure_report.txt** - 下单失败分析报告

## 功能特性

### 1. 日志去重
- 连续相同行去重
- 空行压缩
- 时间戳模式去重
- ID/数字模式去重
- 重要日志保护（启动日志、配置信息等）

### 2. 异常统计
- ERROR/WARN/CRITICAL 日志统计
- 按级别、关键词分类
- 高频异常 Top 10
- 时间分布分析

### 3. 下单失败分析
- 跳过原因分类统计
- 按交易员统计跳过率
- 配置错误识别
- 阈值问题分析
