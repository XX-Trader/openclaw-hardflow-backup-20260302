# 项目维护索引（问题定位）

更新时间：2026-03-04（北京时间）

## 1. 目标与使用方式

目标：后续改问题时，先按“问题类型”定位到目录和文件，再做最小改动。

建议流程：

1. 先看第 4 节“按问题类型定位”找到首查文件。
2. 用第 5 节命令做快速确认（`rg` + 单脚本运行）。
3. 只改首查链路，验证通过后再扩展影响面。

## 4. 按问题类型定位（核心）

### 4.1 定时任务不执行 / 执行异常

首查：

- `cron/jobs.json`（任务是否启用、表达式、payload）
- `scripts/openclaw-ops/cron_setup.py`（安装/更新逻辑）
- `scripts/openclaw-ops/cron_switch.py`（全局开关状态）

再查：

- `scripts/openclaw-ops/ops_cron_runner.py`
- `scripts/openclaw-ops/system_schedule_snapshot.py`

### 4.2 TODO 分配异常 / 路由不合理

首查：

- `scripts/openclaw-ops/todo_patrol.py`
- `scripts/openclaw-ops/policy/policy_enforcer.py`（`next-todo`、`route-task`）
- `scripts/openclaw-ops/policy/routing-rules.json`

再查：

- `scripts/openclaw-ops/policy/CONTEXT_GATE.md`
- `scripts/openclaw-ops/TODO_PATROL_POLICY_FLOW.md`

### 4.3 任务状态、失败升级、积分/统计异常

首查：

- `scripts/openclaw-ops/policy/task_center.py`
- `scripts/openclaw-ops/policy/policy_enforcer.py`

再查：

- `scripts/openclaw-ops/policy/FIELD_DICTIONARY.md`
- `scripts/openclaw-ops/policy/token-pricing.json`

### 4.4 API 巡检误报 / 浏览器巡检问题

首查：

- `scripts/openclaw-ops/api_test_audit.py`
- `scripts/openclaw-ops/init_api_test_config.py`

再查：

- `scripts/openclaw-ops/README.md`（参数示例和约束）

### 4.5 Gate 评分不过 / 回流闭环异常

首查：

- `scripts/hardflow/hardflow-run.sh`
- `scripts/hardflow/check-score-gate.mjs`
- `scripts/hardflow/score-policy.json`

再查：

- `scripts/hardflow/check-api-doc-gate.sh`
- `scripts/hardflow/check-review-test-gate.sh`
- `scripts/hardflow/SCORECARD_SCHEMA.md`

### 4.6 Hook 触发异常 / 拦截行为异常

首查：

- `hooks/hardflow-command-guard/handler.ts`
- `hooks/hardflow-policy-enforcer/handler.ts`
- `hooks/hardflow-stop-gate-reminder/handler.ts`

经验链路相关：

- `hooks/hardflow-experience-capture/handler.ts`
- `hooks/hardflow-experience-recall/handler.ts`
- `hooks/hardflow-experience-evolve/handler.ts`
- `hooks/_lib/experience.ts`

### 4.7 Agent 行为、角色、模型配置问题

首查：

- `agents/agent_index.md`
- `agents/<agent-id>/SOUL.md`
- `agents/<agent-id>/models.json`

多模型切换：

- `scripts/openclaw-ops/switch_model_tier.py`
- `scripts/openclaw-ops/model_tier_profiles.json`

### 4.8 项目索引/文档知识索引不准确

首查：

- `scripts/openclaw-ops/policy/project_index_maintainer.py`
- `.workflow/project-index/project-registry.json`

产物：

- `.workflow/project-index/PROJECT_INDEX.md`
- `.workflow/project-index/project-index.json`
- `.workflow/project-index/DOC_KNOWLEDGE.md`
- `.workflow/project-index/doc-knowledge.json`

## 5. 高频排查命令

```bash
# 1) 先看脏文件，避免误判
git status --short

# 2) 关键词定位（推荐）
rg "next-todo|route-task|create-task" scripts/openclaw-ops/policy
rg "score-gate|SCORE" scripts/hardflow
rg "hardflow-policy-enforcer|command-guard" hooks

# 3) 查看可执行任务配置
cat cron/jobs.json

# 4) 本地执行一次关键巡检（按需）
python scripts/openclaw-ops/ops_cron_runner.py --mode incremental
python scripts/openclaw-ops/todo_patrol.py --task manual:debug

# 5) 重建项目索引（建议改完关键流程后执行一次）
python scripts/openclaw-ops/policy/project_index_maintainer.py \
  --registry .workflow/project-index/project-registry.json \
  --disable-doc-check-updates \
  --disable-doc-fetch-content \
  --disable-memory-index-on-change
```

---

## 6. 修改顺序建议（减少回归）

1. 先改配置文件（`*.json` / `*.env` 示例）确认规则正确。
2. 再改执行器脚本（runner / policy / hardflow）。
3. 最后改通知、汇总、文档索引。
4. 每次只覆盖一个问题链路，避免一次混改多个模块。
