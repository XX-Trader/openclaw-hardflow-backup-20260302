## 1. 目标与结论

结合当前 `docs` 规划文档和项目代码现状，本规范明确以下边界：

1. `home/ubuntu/.openclaw` 是 **运行目录**，只做本地运行与本地 Git 同步，不推送到远程。
2. 仅 `openclaw-hardflow-backup-20260302`（工作流/插件项目仓库）允许推送到远程。
3. 远程推送目标必须受白名单约束，只允许：  
   - `https://github.com/XX-Trader/openclaw-hardflow-backup-20260302.git`  
   - `https://github.com/XX-Trader/openclaw-hardflow-backup-20260302`
4. 定时任务保持精简，仅保留核心链路任务，避免高频重复调度。

## 3. 目录与仓库角色定义

### 3.1 运行目录（不推远程）

- 目录：`/home/ubuntu/.openclaw`
- 角色：运行时配置、状态、报告、缓存、任务状态、巡检中间产物
- 策略：允许本地读写、允许本地 Git 同步（如 pull/fetch），**禁止远程 push**

### 3.2 工作流插件仓库（允许推远程）

- 仓库：`openclaw-hardflow-backup-20260302`
- 角色：`scripts/openclaw-ops`、`hooks`、`skills`、`agents` 等可演进代码
- 策略：允许治理/自我进化后提交并推送到指定 GitHub 远程

## 4. 推送白名单与路径白名单

### 4.1 远程仓库白名单（强约束）

仅允许推送到以下 URL（任一）：

1. `https://github.com/XX-Trader/openclaw-hardflow-backup-20260302.git`
2. `https://github.com/XX-Trader/openclaw-hardflow-backup-20260302`

3. `.workflow/experience/`

## 6. 关键实现映射（代码）

1. Git 推送执行器：`scripts/openclaw-ops/git_sync_push_runner.py`
2. 定时任务安装器：`scripts/openclaw-ops/cron_setup.py`
3. 当前任务清单：`cron/jobs.json`

关键能力：

- `git_sync_push_runner.py`
  - 支持 `fetch` / `pull --ff-only` / `commit` / `push`
  - 支持 include/exclude 前缀过滤
  - 支持 `--require-remote-url` 白名单校验
- `cron_setup.py`
  - 支持安装 `git_sync` 任务
  - 支持默认 include/exclude 策略
  - 支持远程 URL 白名单参数透传
- `cron/jobs.json`
  - 已配置核心任务链路
  - `repo-path` 采用工作流仓库路径变量，而非 `.openclaw` 运行目录

## 7. 环境约定

建议在服务器设置以下变量：

1. `OPENCLAW_WORKFLOW_REPO=/home/ubuntu/openclaw-hardflow-backup-20260302`

说明：

- 未设置时，任务将使用默认回退路径：`$HOME/openclaw-hardflow-backup-20260302`
- `.openclaw` 目录仅作为运行目录，不应作为 `repo-path` 传入推送任务

---

## 8. 验收标准（DoD）

1. `ops_git_sync_push` 仅在白名单远程下执行 push。
2. 当远程 URL 不匹配白名单时，任务失败并输出 `remote_url_not_allowed`。
3. 提交范围不包含 `.workflow/project-index/`、`.workflow/project-index-local/` 与运行态目录，且这些索引产物不再由 Git 跟踪。
4. `.openclaw` 目录不发生远程推送行为。
5. 启用任务数维持在核心基线（5 个）或经评审批准增减。

---

## 9. 变更与回滚

### 9.1 变更顺序

1. 先改任务配置（`cron/jobs.json`）
2. 再改执行器（`git_sync_push_runner.py` / `cron_setup.py`）
3. 最后做 dry-run 验证与线上启用

### 9.2 回滚策略

1. 将 `ops_git_sync_push` 置为 `enabled=false`
2. 恢复上一个 `cron/jobs.json` 备份版本
3. 保留 `.openclaw` 本地同步，不影响运行态任务

---

## 10. 运维提示

如需强制核对当前远程地址：

```bash
git -C /home/ubuntu/openclaw-hardflow-backup-20260302 remote -v
```

如需临时停止所有核心任务推送能力，仅关闭 `ops_git_sync_push` 即可，不影响巡检与索引任务。
