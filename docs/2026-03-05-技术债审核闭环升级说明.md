# 2026-03-05 技术债审核闭环升级说明

更新时间：2026-03-05（北京时间）

## 1. 目标

把 reviewer 从“只扫描、弱闭环”升级为“可追踪技术债闭环”：

1. 扫描发现问题后自动创建技术债任务。
2. 支持任务级审核状态标记（已审/待修复/已验证）。
3. 以低成本模式启用 reviewer（默认日增量 + 周结构）。

---

## 2. 本次变更

### 2.1 任务中心新增审核字段

文件：`scripts/openclaw-ops/policy/task_center.py`

`tasks` 表新增字段（含迁移补列）：

1. `review_status`（默认 `unreviewed`）
2. `review_mode`（如 `daily_incremental` / `weekly_structure`）
3. `review_head`（审查时关联的 head）
4. `reviewed_at`（审查时间）

并同步接入：

1. `create_task` 插入字段
2. `update_task` 可更新字段
3. `get_task` 返回字段

状态枚举：

- `unreviewed`
- `in_review`
- `reviewed`
- `fix_required`
- `fix_verified`

### 2.2 reviewer 扫描自动建技术债任务

文件：`scripts/openclaw-ops/reviewer_cron_runner.py`

新增能力：

1. 对 `daily_incremental/bi_daily_recurring/weekly_structure` 扫描结果自动建 `reviewer_technical_debt` 任务。
2. 去重策略：按 `issue_key -> change_id` 去重，已有 open 任务不重复建单。
3. reopen 策略：若同 issue 历史任务已 `passed/cancelled`，新一轮命中则自动 reopen 为 `pending`。
4. resolved 联动：扫描状态转 `resolved` 时，自动将对应 open 技术债任务标记为 `passed + fix_verified`。
5. 自动补齐任务上下文：`repo/path/category/severity/title/detail/run_id`。

新增参数：

1. `--create-techdebt-task / --no-create-techdebt-task`（默认开启）
2. `--techdebt-min-severity high|medium`（默认 `medium`）
3. `--techdebt-max-tasks-per-run`（默认 `8`）
4. `--techdebt-assignee`（可覆盖默认分配）

### 2.3 reviewer 安装器增强

文件：`scripts/openclaw-ops/install_reviewer_scan_jobs.py`

新增与修复：

1. 新增 profile：`techdebt`
   - `enable_hourly=false`
   - `enable_daily=true`
   - `enable_bi_daily=false`
   - `enable_weekly=true`
2. 路径规范化：统一转 shell 可执行路径（`/`），避免 `\\home\\...` 写入 jobs 导致命令异常。

### 2.4 调度示例同步

文件：`cron/jobs.json`

1. reviewer 命令路径改为 `$HOME/.openclaw/...`。
2. reviewer 开关调整为技术债模式：
   - `reviewer_incremental_daily_4am` => `enabled=true`
   - `reviewer_weekly_structure_review` => `enabled=true`
   - `reviewer_git_update_hourly` / `reviewer_recurring_bi_daily` => `enabled=false`
