# 工作流主升级方案

## 目标

将任意软件项目的需求、计划、隔离实现、验证、审查、可选部署、记忆写回和 Git 发布连接为可回滚闭环。

## 唯一 owner

- 状态机：`skills/library/project-delivery-pipeline/scripts/pipeline_runner.py`
- Runtime 安装：`setup.py` 与 `runtime_installer.py`
- 控制面：`skills/library/control-plane-ops/`
- 质量门禁：`skills/openclaw-hardflow-automation/`
- 当前需求：`requirements.md`

## 升级约束

1. 所有项目差异通过参数、环境变量或项目契约注入。
2. 失败只回流到对应阶段，不重复已通过的长链。
3. 每个新增行为必须有 owner 测试、版本记录和回滚点。
4. 提交前执行定向测试、全量测试、敏感信息检查和远端回读。
