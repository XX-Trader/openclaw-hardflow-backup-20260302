## 管理规则

1. **每完成一项**：从 `todo.md` 移到 `done.md`，补上完成描述
2. **每完成一个阶段**：更新本文件阶段状态，跑 48h 稳定性验证
3. **任务派发前确认 5 要素**：内容 / 流程 / 预期 / 角色 / 时间
4. **风险分级执行**：低风险自动、高风险人工审核
