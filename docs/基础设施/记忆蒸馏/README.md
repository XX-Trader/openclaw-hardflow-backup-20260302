## 1. 核心定位

**从 Agent 会话中提取可复用知识，自动归档到对应记忆层级。**

与 Hermes 原生记忆整理（文件生命周期管理）分层，本模块解决**知识层面**的蒸馏：

| 维度 | Hermes 原生记忆整理 | 知识蒸馏（本模块） |
|------|:--:|:--:|
| 对象 | .md 文件 | Agent 会话内容 |
| 操作 | 压缩/归档/修剪 | 提取/分类/沉淀 |
| 输入 | 记忆目录 | sessions/ 目录 |
| 输出 | 整理报告 | 事实/经验/技能候选 |

## 2. 子功能清单与验收状态

| # | 子功能 | 描述 | 验收标准 | 状态 |
|:-:|--------|------|---------|:----:|
| D1 | 会话清洗 | 读取 24h 内 Agent sessions，过滤噪声 | 过滤率 ≥ 60%（心跳/空回复/重复 stdout 可去除） | ⬜ |
| D2 | 知识分类 | 将清洗后内容分为事实/经验/模式 3 类 | 分类准确率人工抽检 ≥ 80% | ⬜ |
| D3 | 事实归档 | 高价值事实写入 `USER.md / MEMORY.md` 热层；旧 `openclaw-memory/` 仅保留兼容/归档 | 去重率 100%（不写重复事实） | ⬜ |
| D4 | 经验归档 | 经验类写入 .workflow/experience/ | 按主题文件聚合，支持追加 | ⬜ |
| D5 | 模式识别 | 同一操作 ≥3 次时标记为技能候选 | 生成 SKILL.md 草稿 + 人确认 | ⬜ |
| D6 | 去重合并 | 与现有记忆对比，冲突标注待裁决 | 零漏写、零覆盖 | ⬜ |
| D7 | 蒸馏报告 | 产出结构化报告（JSON + MD） | 包含新增条目数、分类分布、冲突列表 | ⬜ |
| D8 | Cron 集成 | 注册为每日定时任务 | 复用现有 `optimize 自我进化总结` Job | ⬜ |

## 4. 边界约束

- **只读会话**：蒸馏引擎只读 sessions，绝不修改/删除原始会话记录
- **LLM 依赖**：D2 分类需要 LLM，但 D1/D3/D4/D6/D7 纯脚本
- **人工确认**：D5 模式升级为 Skill 必须经过人工确认
- **与 Hermes 原生记忆整理互不干扰**：Hermes 管文件生命周期，蒸馏管内容价值；两者可并行
