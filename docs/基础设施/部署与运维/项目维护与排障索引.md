# 项目维护与排障索引

| 问题 | 事实源 | 动作 |
| --- | --- | --- |
| 安装目标不正确 | `setup.py --dry-run --emit-json` | 修正 Runtime 参数后重跑 dry-run |
| Profile 不完整 | `config/runtime-profiles/` | 比较模板和环境变量注入结果 |
| Cron 路径漂移 | `cron/jobs.json`、`export_schedule_registry.py` | 导出注册表并核对已安装脚本 |
| Cron 卡住 | `recover_stale_cron_running_state.py` | 先 dry-run，再仅恢复过期状态 |
| 项目流水线失败 | `.workflow/pipeline-runs/<run_id>/` | 从 `failed_stage` 指向的失败链续跑 |
| 配置变更异常 | `config_watchdog.py` | 对比快照并按审计结果回滚 |

排障结论必须包含：复现命令、退出码、输入范围、实际输出、已修复边界和剩余边界。
