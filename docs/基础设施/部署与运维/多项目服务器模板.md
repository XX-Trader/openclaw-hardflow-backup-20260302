# 多项目 Runtime 模板

每个项目使用独立 Runtime Home、状态目录和任务库，避免共享可变状态。

| 参数 | 项目 A | 项目 B |
| --- | --- | --- |
| `--runtime-home` | `<ROOT>/runtime-a` | `<ROOT>/runtime-b` |
| `--runtime-name` | `project-a` | `project-b` |
| `--project-memory-dir` | `<ROOT>/memory-a` | `<ROOT>/memory-b` |
| `--task-center-db` | `<ROOT>/state-a/task-center.db` | `<ROOT>/state-b/task-center.db` |

```bash
python3 setup.py --runtime-home <ROOT>/runtime-a --runtime-name project-a --dry-run --emit-json
python3 setup.py --runtime-home <ROOT>/runtime-b --runtime-name project-b --dry-run --emit-json
```

约束：

1. 凭证只由各 Runtime 的私有环境文件注入。
2. 项目源码、记忆、状态和通知目标不跨项目复用。
3. 同步前比较版本与目标清单；失败节点单独重试。
4. 每个项目保留独立健康检查和回滚记录。
