# 安装与工作流部署说明

## 阶段 1：只读预检

```bash
python setup.py --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --dry-run --emit-json
```

确认目标路径、文件清单、Cron 任务、通知目标和时区。

## 阶段 2：安装

```bash
python setup.py --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --emit-json
```

## 阶段 3：验证

- JSON 文件可解析。
- Runtime Profile 健康检查通过。
- 选定的 Cron 任务引用已安装脚本。
- 未配置部署命令时，交付流水线将部署标记为显式跳过，而不是猜测项目命令。

## 回滚

使用安装前备份和安装输出中的托管清单恢复；不覆盖目标 Runtime 的非托管文件。
