# 安装与工作流部署说明

## 阶段 1：只读预检

```bash
python setup.py --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --dry-run --emit-json
```

确认目标路径、文件清单、Cron 任务、通知目标和时区。

## 阶段 2：安装

```bash
python setup.py --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --emit-json
```

## 阶段 3：验证

- JSON 文件可解析。
- Runtime Profile 健康检查通过。
- 选定的 Cron 任务引用已安装脚本。
- 未配置部署命令时，交付流水线将部署标记为显式跳过，而不是猜测项目命令。

## 回滚

先预览最近一次快照的恢复范围，再执行回滚：

```bash
python setup.py rollback --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --dry-run --emit-json
python setup.py rollback --runtime-home <RUNTIME_HOME> --runtime-name <RUNTIME_NAME> --emit-json
```

安装器恢复升级前存在的受管文件，移除本次新增的受管文件，并保留目标 Runtime 的非托管文件。回滚后旧安装清单会一并恢复，因此可继续回退上一层快照。
