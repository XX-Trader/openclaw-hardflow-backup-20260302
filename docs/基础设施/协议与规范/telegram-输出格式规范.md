# 📌 Telegram 多列输出规范（已生效）

> 所有列表类、重复列结构的输出，统一遵循以下规则，保证对齐可复制。

## 格式模板

```
----------------------------------------------------------------------------------------------------------
| 列1类型   | 列2名称           | 列3状态 | 列4触发方式       | 列5核心能力                                |
----------------------------------------------------------------------------------------------------------
| 固定宽度  | 固定宽度自适应内容 | 固定宽度 | 固定宽度自适应内容 | 剩余宽度自动换行，行首对齐，竖线严格对齐    |
----------------------------------------------------------------------------------------------------------
```

## 规则清单

1. **代码块包裹**：所有多列输出统一用 ` ``` ` 代码块包裹，复制粘贴到任意文档/编辑器不会乱格式
2. **竖线严格对齐**：每列竖线严格对齐，分隔线用连续 `-` 填充，每行首尾必有竖线
3. **Emoji 前缀 + 固定宽度**：分类 emoji 统一前缀，状态、触发方式列长度固定，核心能力列自动换行缩进对齐
4. **动态列宽**：列数动态增减时自动调整每列宽度，优先保证名称、状态、核心能力列的可读性
5. **全局生效**：以后所有类似场景输出自动套用，无需额外调整

## 适用场景

- Agent 列表 / 状态汇总
- Cron Job 列表
- 工作流清单
- 技能列表
- 配置对比表
- 任何包含重复列结构的输出
