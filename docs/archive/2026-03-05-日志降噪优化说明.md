# 2026-03-05 日志降噪优化说明

## 目标

- 减少 cron 机器人无价值刷屏（例如 `Let's run...` 前置话术）。
- 减少本地备份任务在正常情况下的长列表输出。
- 保留可选详细模式，便于排障时临时打开。

## 变更点

### 1) `scripts/openclaw-ops/local_git_backup_runner.py`

- 新增参数：
  - `--notify-on {errors-only,on-change,always}`（默认：`errors-only`）
  - `--list-changed-files`（默认关闭）
  - `--max-listed-files`（默认：`20`）
- 新默认行为：
  - 成功 commit 但无错误时，默认输出 `NO_REPLY`（不再日常刷屏）。
  - 只有错误时才通知。
  - 变更文件列表默认不输出。

### 2) `scripts/openclaw-ops/todo_patrol.py`

- 新增参数：
  - `--output-mode {summary,verbose,silent}`（默认：`summary`）
- 行为说明：
  - `summary`：输出精简摘要（任务数、错误数、任务样例）。
  - `verbose`：保持原有详细输出。
  - `silent`：成功时统一 `NO_REPLY`，仅异常时输出。

### 3) 安装脚本参数透传

- `scripts/openclaw-ops/install_todo_patrol_job.py`
  - 新增 `--output-mode`，并写入调度命令。
- `scripts/openclaw-ops/install_local_openclaw_backup_job.py`
  - 新增 `--notify-on`、`--list-changed-files`、`--max-listed-files`，并写入调度命令。
- `scripts/openclaw-ops/install_workflow_profile.py`
  - 新增 `--todo-output-mode`（默认 `summary`）。
  - 新增 `--local-backup-notify-on`（默认 `errors-only`）。

### 4) 调度提示词收敛

- `scripts/openclaw-ops/cron_setup.py`
- `scripts/openclaw-ops/install_todo_patrol_job.py`
- `scripts/openclaw-ops/install_local_openclaw_backup_job.py`

以上脚本生成的 `payload.message` 已增加硬约束：禁止输出 `Let's ...` / `Okay ...` 之类前置话术，仅返回命令原始输出。

## 推荐配置

- TODO 巡检：`--output-mode silent`（若你希望几乎不推送）
- 本地备份：`--notify-on errors-only`（默认）

## 最小回滚方案

- 如果需要恢复旧行为：
  - 本地备份改为：`--notify-on on-change --list-changed-files`
  - TODO 巡检改为：`--output-mode verbose`
