目标：实现“任务可自动分发 + agent 可执行 + 回传可落库 + 可定时跑”的基础闭环，尽量减少人工问答。

3. 通过 cron job 定时驱动执行器，形成 `todo_patrol -> task_center -> task_executor_runner` 的闭环。
4. 产出可验收报告（JSON 运行报告 + task-report 可观测信息）。

## 3. 架构闭环（当前可运行）

1. `todo_patrol.py` 负责将可执行项写入 task-center（create/assign）。
2. `task_executor_runner.py` 定时读取 `status=pending` 任务。
3. 每个任务执行前走 `pre-stage`，执行后走 `post-stage`。
4. runner 调用 `openclaw agent`，解析结构化结果，调用 `report-agent-result` 回写。
5. task-center 中形成完整证据：
   - `events`
   - `stage_runs`
   - `agent_reports`
   - `token_usage`
6. `install_task_executor_job.py` 将上述 runner 装入 OpenClaw cron。

## 5. 你现在可以直接用的命令

### 5.1 初始化 runtime agents

```bash
python skills/library/openclaw-workflow-manager/scripts/bootstrap_runtime_agents.py --emit-json
```

### 5.2 手动跑一轮任务执行器

```bash
python skills/library/control-plane-ops/scripts/policy/task_executor_runner.py \
  --db ~/.openclaw/ops/task-center/task_center.db \
  --max-tasks 3 \
  --emit-json
```

### 5.3 安装执行器定时任务

```bash
python scripts/openclaw-ops/install_task_executor_job.py \
  --jobs-file ~/.openclaw/cron/jobs.json \
  --executor-py ~/.openclaw/ops/policy/task_executor_runner.py \
  --db ~/.openclaw/ops/task-center/task_center.db \
  --channel telegram --to "<chat_id>"
```

### 5.4 一键安装全工作流（已包含 task executor）

```bash
python scripts/openclaw-ops/install_workflow_profile.py \
  --profile core \
  --workflow-repo-path ~/workflow-infra
```
