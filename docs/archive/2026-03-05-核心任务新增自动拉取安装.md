# 核心任务新增：自动拉取并安装（2026-03-05）

## 新增目标
- 增加核心定时任务：每 1 小时检查并拉取 `https://github.com/XX-Trader/openclaw-hardflow-backup-20260302` 最新代码。
- 拉取成功后自动执行安装命令。
- 安装失败不再创建 `optimization-agent` 任务，只保留失败状态与完整日志。

## 已实现内容
- 新增执行器：
  - `scripts/openclaw-ops/auto_update_install_runner.py`
  - 功能：`git fetch` -> `git pull --ff-only`（有更新时）-> 执行安装命令 -> 落盘日志。
- 接入安装器：
  - `scripts/openclaw-ops/cron_setup.py`
  - 新增 job：`ops_auto_update_install_hourly`
  - 默认周期：`3600000ms`（1 小时）
- 接入工作流安装脚本：
  - `scripts/openclaw-ops/install_workflow_profile.py`
  - `core` 任务集新增 `#9`（自动拉取并安装）

## 失败策略（按最新要求）
- 安装失败：允许失败，不自动派发优化任务。
- 必须落盘：
  - 安装 stdout：`~/.openclaw/ops/update-install-runs/*.install.stdout.log`
  - 安装 stderr：`~/.openclaw/ops/update-install-runs/*.install.stderr.log`
  - 运行报告：`~/.openclaw/ops/update-install-runs/*.json`

## 关键参数
- `cron_setup.py`
  - `--install-auto-update-install-job`
  - `--auto-update-install-every-ms 3600000`
  - `--auto-update-install-repo-path <workflow_repo>`
  - `--auto-update-install-install-cmd "<install_command>"`
